# Правила агента — Content Factory

Telegram-канал о вине. Материалы готовит и публикует бот.

---

## Источник истины

| Файл | Что определяет |
|---|---|
| `editorial-policy.md` | Редакционная политика: голос, форматы, доказательность, запреты. Главный документ по содержанию |
| `channel.yml` | Ритм публикаций, дата отсчёта, слоты и их время |
| `bot/generator-brief.md` | Механика пакетного прогона генератора |
| `bot/check.py` | Проверка постов перед выпуском, падает на запрещённых конструкциях |
| `sources/wines.yml` | Бутылки от владельца — единственный источник тем |
| `sources/producers.md` | Справочник производителей портфеля |
| `published/` | Журнал канала: что и когда вышло, с источниками во frontmatter |

При расхождении выигрывает `editorial-policy.md`.

---

## Два контура

Система разделена на генерацию и публикацию. Они не знают друг о друге,
связь только через файлы в `posts/`.

### Генератор — 1 и 15 числа

Агентская сессия по расписанию готовит пакет на две недели вперёд: считает
активные дни, читает журнал, выбирает вина и ракурсы, исследует по источникам,
пишет файлы в `posts/` и коммитит. Подробности — в `bot/generator-brief.md`.

Если по вину не хватило источников, слот получает `status: needs_sources`
и в канал не уходит. Пропущенный слот лучше выдуманного факта.

### Публикатор — каждый активный день

`bot/publish.py` запускается по cron дважды в день. Сам проверяет, публикационный
ли сегодня день, берёт файл нужного слота, отправляет в Telegram только при
`status: ready`, дописывает во frontmatter факт публикации и переносит файл
в `published/`.

---

## Ритм

Ритм: два дня публикуем, один пропускаем. Цикл из трёх дней повторяется
от `start_date`, смена месяца отсчёт не обнуляет, привязки к дням недели нет.

| Время МСК | Слот | Файл | Обязателен |
|---|---|---|---|
| 12:00 | `main` | `posts/YYYY-MM-DD-main.md` | да |
| 19:00 | `companion` | `posts/YYYY-MM-DD-companion.md` | нет, только при самостоятельной ценности |

Пропуск слота не сдвигает следующие даты и не удваивает следующий день.

---

## Запрещённые конструкции

Список ведётся в `bot/generator-brief.md` по факту найденных ошибок, а не
по теории. Машинно проверяемая часть зашита в `bot/check.py`.

Коротко: антитезы в обоих порядках, служебные связки, проговаривающие
структуру, жирные врезки в начале абзацев, markdown вместо HTML, перебор
тире, вывод вкуса из механики производства, перенос параметров с другого
урожая, гарантии состояния бутылки.

Перед коммитом готовых постов запускать `python bot/check.py`.

---

## Статусы

| Статус | Что значит |
|---|---|
| `ready` | Проверку прошёл, публикатор отправит |
| `needs_sources` | Источников не хватило, слот пропускается |
| `needs_input` | Нужен ответ владельца |
| `publication_blocked` | Текст готов, но отправка невозможна |
| `published` | Отправлен, записаны время и id сообщения |

---

## Ручной запуск

Workflow «Публикация в Telegram» принимает `slot` (`main` / `companion`)
и `date` — для выпуска пропущенного поста задним числом.
