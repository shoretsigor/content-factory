# Архив

Материалы прошлой механики канала (два поста в день, тексты 500–900 знаков,
написанные вручную). Сохранены для истории.

- `tov.md` — прежний tone of voice. **Отменён** `editorial-policy.md`: там другой
  объём (1800–2800 знаков), другой голос и другие правила. Не использовать.
- `content_plan.md` — прежний ручной контент-план. Заменён расчётным календарём:
  активные дни считаются из `channel.yml`, память канала лежит в `published/`.
