# Архив

Материалы прошлой механики канала (два поста в день, тексты 500–900 знаков,
написанные вручную). Сохранены для истории.

- `tov.md` — прежний tone of voice. **Отменён** `editorial-policy.md`: там другой
  объём (1800–2800 знаков), другой голос и другие правила. Не использовать.
- `content_plan.md` — прежний ручной контент-план. Заменён расчётным календарём:
  активные дни считаются из `channel.yml`, память канала лежит в `published/`.

## Интерактивный бот (отключён 17.09.2026)

`interactive.py` — бот «идея → 3 варианта через Claude API → публикация вручную»,
работал на Railway как worker. Отключён: генератор по редполитике делает ту же
работу, а два бота писали в одну папку `posts/` по несовместимым правилам —
интерактивный выдёргивал запланированные посты раньше слота и удалял файлы,
оставляя дыры в расписании.

Вместе с ним удалены `Procfile` и корневой `requirements.txt` — они нужны были
только для сборки на Railway.

**Важно:** удаление Procfile останавливает будущие деплои, но не гасит уже
запущенный контейнер. Сервис нужно остановить в панели Railway вручную.
